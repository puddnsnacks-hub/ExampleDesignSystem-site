# Icons

41 IBM Carbon marks (Apache 2.0), filled, on a 32-unit grid. Single ink: each file draws in black. In a page the same marks come from the sprite that `components/bundle.js` inserts, and take the color of what they sit in.

Draw one through the sprite: `<svg class="xds-icon" data-size="md" aria-hidden="true"><use href="#xds-search"></use></svg>`. Sizes `sm` 16, `md` 20, `lg` 24, `xl` 32, `2xl` 48. No two statuses share a silhouette.
